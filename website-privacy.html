Website privacy

Updated September 26, 2026 · Operator: minus

This notice covers the CriteriaCue promotional website. The Chrome extension has a separate privacy policy.

Limited website statistics

We use PostHog to understand visits, broad traffic sources and clicks on the “Add to Chrome” links. We send the fixed page address, recognized source and campaign labels, basic browser and operating-system information, and which installation link was clicked. We discard arbitrary URL parameters, URL fragments and referring-page paths.

PostHog's cookieless mode uses a server-generated hash to estimate visitors, without placing analytics cookies or analytics identifiers in your browser's local or session storage. Network requests necessarily expose your IP address and browser information to the service. We disable geographic enrichment and identified person profiles. Visitor totals are estimates.

Session recordings, automatic click and form capture, heatmaps and error capture are disabled. We do not collect text entered in the role templates, candidate information, LinkedIn profile content, or API keys. The extension does not contain this website analytics code.

We skip analytics when your browser signals Do Not Track or Global Privacy Control. Blocking PostHog does not prevent you from using the site or opening the Chrome Web Store. This privacy page does not load analytics.

Hosting and external services

The website is hosted on GitHub Pages. GitHub and PostHog process network requests according to their own policies: GitHub privacy statement and PostHog privacy policy. Following a Chrome Web Store or other external link takes you to that service.

Contact

For questions about this website, email support@minus.team. Do not include candidate information or credentials.
